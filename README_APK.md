# 📱 دليل بناء واستخراج ملف APK وتوقيعه لنشره على متجر Google Play

أهلاً بك! هذا هو الدليل الشامل المخصص لاستخراج ملف **APK / AAB** الخاص بـ **"تطبيق مؤسسة الباقيات الصالحات"** بنجاح.

---

## 🛠️ الطرق المتاحة لبناء الـ APK

### 🌟 الطريقة الأولى: باستخدام Flet CLI مباشرة (يوصى بها)

إذا كان لديك بيئة Python مثبّتة، يمكنك تحزيم التطبيق فوراً باستخراج أمر واحد:

```bash
pip install flet
flet build apk app/main_app.py
```

سيقوم الأمر تلقائياً بتجميع كود **C++ Engine** واجهات التطبيق في ملف `app-release.apk` ستجده داخل مجلد:
`build/apk/app-release.apk`

---

### 🚀 الطريقة الثانية: التحزيم عن طريق Google Colab (بدون أي أدوات محليّة)

إذا أردت استخراج ملف الـ APK بسرعة دون الحاجة لإعداد بيئة أندرويد على جهازك الشخصي:

1. افصل مجلد المشروع وضعه في ضغط Zip أو ارفعه على حسابك في Google Drive / Colab.
2. افتح نوت بوك جديد في [Google Colab](https://colab.research.google.com/).
3. شغل الأوامر التالية:

```python
!pip install flet
!flet build apk app/main_app.py
```

4. حمل ملف الـ `app-release.apk` مباشرة إلى هاتفك لتجربته أو رفعه للمتجر!

---

## 🔑 خطوات النشر الرسمي على متجر Google Play Store

لنشر التطبيق رسمياً على متجر **جوجل بلاي (Google Play Console)**:

1. **توليد مفتاح التوقيع (Keystore)**:
   ```bash
   keytool -genkey -v -keystore baqiyat_key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias baqiyat_alias
   ```

2. **بناء الحزمة المعتمدة للرفع (App Bundle - `.aab`)**:
   ```bash
   flet build aab app/main_app.py
   ```

3. **إنشاء حساب مطور رفع التطبيق**:
   - توجه إلى [Google Play Console](https://play.google.com/console).
   - قم بإنشاء تطبيق جديد باسم: **تطبيق مؤسسة الباقيات الصالحات**.
   - ارفع ملف `.aab` المستخرج وصور التطبيق وتفاصيل الأقسام السبعة.
